# 导出、作者与分享保护

在首页长按一张卡片，选择**导出**，即可填写作者资料并选择普通分享或受保护分享。

## 作者与简介

导出面板支持填写：

| 字段 | 说明 |
| --- | --- |
| 作者名称 | 分享包中显示的署名；没有署名时可使用“未署名” |
| 主页或社交链接 | 可选，供接收者查看作者主页 |
| 作者简介 | 可选，介绍作者或账号 |
| 组件简介 | 可选，说明卡片用途、数据来源或使用方法 |

作者资料是分享署名，不代表实名或平台认证。

导入后，点卡片会先进入**组件信息**页。这里可以查看预览、作者、简介、保护状态和每项权限；拥有“编辑组件”权限时，再点**编辑组件**进入编辑器。

## 普通分享

关闭**受保护分享**时，导出的卡片可以离线导入，接收者拥有完整编辑权限。适合自己的设备之间迁移，或分享允许自由修改的卡片。

## 受保护分享

开启**受保护分享**后，可以限制授权设备数，并分别设置六项权限：

| 权限 | 作用 |
| --- | --- |
| 修改作者信息 | 修改资料署名 |
| 编辑组件 | 修改布局、属性与组件简介 |
| 访问代码 | 查看、编辑或复制源码 |
| 复制组件 | 复制整个组件 |
| 再次导出 | 再次分享组件包 |
| 投稿 | 提交到组件社区 |

每项权限有三种状态：

- **直接允许**：导入后立即可用。
- **密码解锁**：输入正确密码后可用。
- **始终禁止**：密码也不能解锁。

只要有一项选择**密码解锁**，就需要设置至少 8 位密码。同一个密码会解锁该分享包中所有“密码解锁”权限。

导入后如仍有“需要密码”的权限，可在**组件信息**页输入作者密码。验证成功后，这些权限会显示为“已用密码解锁”。

:::warning
密码用于解锁操作权限，不是 ZIP 解压密码，也不是首次导入密码。首次导入受保护分享需要联网完成客户端验证，并受授权设备数限制。
:::

## 哪些信息仍然公开

受保护分享会加密卡片布局、代码、设置定义和随包资源。为了让接收者在导入前识别内容，预览图、作者资料、组件简介和权限摘要仍然可见。

## 平台限制

鸿蒙版与 iOS 版使用相同的外层目录结构，但内容协议和服务接口分别演进。鸿蒙分享包只能由鸿蒙版导入，不能与 iOS 版互相导入。
