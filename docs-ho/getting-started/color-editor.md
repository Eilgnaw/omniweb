# 颜色编辑

在属性编辑器中点“文字色”“前景色”或“背景色”的编辑按钮，可以设置纯色、渐变和普通／深色两套配色。组件配置中的颜色设置使用同一套编辑方式。

## 普通与深色配色

打开“深色模式”后，会出现独立的深色配色区域：

- 已有普通配色时，先复制一份作为深色配色，再分别调整。
- 尚未设置颜色时，普通配色从白色开始，深色配色从黑色开始。
- 关闭开关会移除深色配色，组件在深色外观下继续使用普通配色。

这个开关控制组件的配色，不改变 App 的外观。选好颜色后，点顶部“确定”提交；“重置”恢复刚进入颜色编辑页时的设置，“取消”放弃本次编辑。

## 调色盘

点纯色色块、编辑按钮或渐变色块，可以打开调色盘。

| 页签 | 用法 |
| --- | --- |
| 最近使用 | 查看最近选择的颜色，最多保留 30 项；下方有黑色、白色、透明等快捷颜色 |
| 预设 | 按“系统”“背景”“前景”选择配色；系统颜色采用鸿蒙对应配色 |
| 我的配色 | 保存当前颜色、自定义添加，或使用已经收藏的配色；最多保留 48 项 |

长按最近颜色或预设色块可收藏，长按收藏色块可移除。再次使用同一配色会将它移到最近使用的前面；达到上限时会移除最早的项目。

双色色块包含普通、深色两个颜色。选择它时，只替换正在编辑的那一组颜色，不会同时改动另一组，也不会自动打开深色模式。

在“最近使用”中点 `+` 可自定义调色，也可以直接填写颜色值。自定义调色支持调整颜色和不透明度，透明区域用棋盘格表示。

调色页的“确定”先把颜色带回上一页，最后还要在属性颜色编辑页点“确定”。取消调色不会覆盖原来的颜色；已经记录的最近使用和主动收藏会保留。

## 渐变

“颜色样式”可选纯色、线性、径向和角度。切换为纯色时显示第一个颜色，再切回渐变可以继续编辑原来的色列。

- 点色块编辑，点“添加”新增，点色块角上的减号删除；至少保留一个色标。
- 开启深色模式后，增删色标会同步普通与深色两组；修改某个色标的颜色只影响当前组。
- “当前色标”中可以调整位置，常用范围是 `0` 到 `1`，也可以使用变量。
- 渐变参数区域提供方向、中心、半径或角度设置，具体字段随样式变化。

## 手动输入与变量

在“手动输入”中点编辑按钮，可以一次填写整套配色：

| 输入 | 作用 |
| --- | --- |
| `#0A59F7` | 单个颜色 |
| `#000000\|#FFFFFF` | 普通黑色，深色白色 |
| `#0A59F7,#34C759` | 两个渐变颜色；当前为纯色时会切换为线性渐变 |
| `#0A59F7,#34C759\|#80B3FF,#82E5A0` | 普通与深色各两个渐变颜色 |
| `${color}` | 整段绑定颜色变量，也可以绑定完整颜色对象 |
| `${startColor},${endColor}` | 用变量设置渐变色标 |

逗号 `,` 分隔色标，竖线 `|` 分隔普通与深色配色。替换后色标数量相同会保留原位置，数量变化会均匀排列。非法输入会显示提示，不覆盖已有配色；整段留空可以清除颜色。

变量也可以通过“变量”按钮选择。变量不会加入最近使用或收藏。

## 透明度格式

鸿蒙版使用 `#RRGGBB` 或 `#AARRGGBB`。八位颜色的**前两位**表示透明度：`00` 全透明，`FF` 不透明。

| 颜色值 | 效果 |
| --- | --- |
| `#0000FF` | 不透明蓝色 |
| `#800000FF` | 约 50% 不透明的蓝色 |
| `#00000000` | 完全透明 |

## 仪表和文字描边

仪表颜色、文字描边和组件配置共用最近使用与收藏。仪表仍可设置单色、渐变位置和分段权重，文字描边仍可设置宽度和颜色变量。

仪表和文字描边选取双色预设时，会保存当前编辑器预览外观对应的一个颜色；它们不会因此新增普通／深色两套配色。
