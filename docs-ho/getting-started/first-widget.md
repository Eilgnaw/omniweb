# 做出第一个卡片

这份教程会带你完成一张显示接口数据的 `2*4` 桌面卡片。预计用时：10 分钟。

## 1. 新建卡片

打开 Omni，在首页右上角点 `+`，选择**桌面**和尺寸 **`2*4`**，输入名称后进入编辑器。

新卡片默认是空白画布。长按画布或点底部 `+` 添加第一个组件。

## 2. 添加布局

按顺序添加：

1. 一个**横排**作为根容器。
2. 在横排中添加一个**图标**。
3. 再添加一个**纵列**。
4. 在纵列中添加两个**文字**，分别显示标题和数值。

组件树应当是：

```text
横排
├─ 图标
└─ 纵列
   ├─ 文字
   └─ 文字
```

## 3. 获取数据

切到底部“代码”，粘贴：

```js
let icon = "cloud"
let title = "暂时无法加载"
let value = "--"

try {
  const request = new Request("https://2f0.cn/api/omni")
  const data = await request.fetchJSON()

  icon = data.icon || "cloud"
  title = data.title || data.omni || "今日数据"
  value = data.value ?? "--"
} catch (error) {
  console.error("请求失败：", error)
}
```

点**运行**。日志没有异常时，`icon`、`title` 和 `value` 已经可以绑定。

## 4. 绑定组件字段

| 组件 | 字段 | 填写 |
| --- | --- | --- |
| 图标 | 图标 | `${icon}` |
| 第一个文字 | 内容 | `${title}` |
| 第二个文字 | 内容 | `${value}` |

如果预览为空，先重新运行代码，再在日志中输出变量检查。

## 5. 建议下次刷新

在脚本最后添加：

```js
setUpdateFreq(30) // 建议系统 30 分钟后刷新
```

这是建议，不保证精确到 30 分钟。

## 6. 保存并添加到桌面

1. 在编辑页右上角选择**更多 → 添加至桌面**。
2. 当前内容会保存并绑定到新卡片。
3. 回到桌面查看结果。

也可以在 Omni 首页长按卡片后选择“添加至桌面”。如果系统不显示该入口，请从桌面卡片库添加 Omni 卡片，再在系统编辑中选择同尺寸卡片。
