# 仪表

仪表用环形进度显示一个值在指定范围中的位置，适合完成率、电量、健康分和预算占用。

## 最快用法

| 字段 | 示例 |
| --- | --- |
| 当前值 | `0.72` / `${progress}` |
| 最小值 | `0` |
| 最大值 | `1` / `100` |
| 起始角度 | `210` |
| 终止角度 | `150` |
| 环宽 | `12` |

当前值要落在最小值和最大值之间。

## 属性

| 字段 | 常用填写 | 作用 |
| --- | --- | --- |
| 当前值 | `0.6` / `${value}` | 当前进度 |
| 最小值 / 最大值 | `0` / `1` | 数值范围 |
| 起始角度 / 终止角度 | `210` / `150` | 仪表环范围 |
| 环宽 | `12` / `12vp` | 环的粗细；不支持百分比 |
| 颜色 | 颜色编辑器或变量 | 单色、线性渐变或分段颜色 |
| 宽 / 高、偏移、内外边距 | 数字或变量 | 通用布局字段 |
| 显示、背景色、圆角、旋转、不透明度 | 固定值或变量 | 通用视觉字段 |

## 中心内容和说明

仪表只识别直接放入的可见**层叠**：

| 子组件 | 结果 |
| --- | --- |
| 没有层叠 | 只显示仪表环 |
| 1 个层叠 | 显示为中心内容 |
| 2 个以上层叠 | 第一个显示在中心，最后一个显示为说明 |

需要多个文字或图标时，先把它们放进层叠，再把层叠放进仪表。

## 动态颜色

分段颜色：

```js
let colors = {
  kind: "segments",
  segments: [
    { color: "#34C759", weight: 30 },
    { color: "#FF9500", weight: 40 },
    { color: "#FF3B30", weight: 30 }
  ]
}
```

线性渐变：

```js
let colors = {
  kind: "linear",
  stops: [
    { color: "#0A59F7", offset: 0 },
    { color: "#34C759", offset: 1 }
  ]
}
```

在颜色面板中把变量绑定设为 `${colors}`。

:::warning 说明内容需要 API 23+
低于 API 23 时只显示仪表环和中心内容，不显示说明。
:::

分段颜色最多 9 段，超过部分会截断。
