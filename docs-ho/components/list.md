# 列表

列表连续展示多条可滚动内容，适合待办、新闻、排行、日程和交易记录。

## 最快用法

1. 添加**列表**。
2. 放入一个根子组件作为每项模板。
3. 在“数据源（循环）”中填写 `{items[item]}`。
4. 给列表设置明确高度，确保可以滚动。

## 属性

| 字段 | 常用填写 | 作用 |
| --- | --- | --- |
| 方向 | `vertical` / `horizontal` | 上下或左右滚动 |
| 间距 | `0` / `8` | 每项之间的距离 |
| 数据源（循环） | `{items[item]}` | 按数组重复模板 |
| 初始位置 | `0` / `3` | 首次显示的项目，下标从 `0` 开始 |
| 列数 / 行数 | `1` / `2` | 竖向表示列数；横向表示行数 |
| 交叉轴对齐 | `start` / `center` / `end` | 列表项在另一方向的位置 |
| 滚动条 | `off` / `auto` / `on` | 滚动条显示方式 |
| 边缘效果 | `spring` / `none` | 是否显示回弹 |
| 分割线宽度 / 颜色 | `1` / `#1A000000` | 项目之间的分割线 |
| 宽 / 高、偏移、内外边距 | 数字、百分比或变量 | 通用布局字段 |
| 显示、背景色、圆角、旋转、不透明度 | 固定值或变量 | 通用视觉字段 |

## 示例：待办列表

```js
let items = [
  { title: "买咖啡", time: "08:30" },
  { title: "晨会", time: "09:00" },
  { title: "整理账单", time: "20:00" }
]
```

列表设置：

- 方向：`vertical`
- 数据源（循环）：`{items[item]}`
- 高：`100%`
- 间距：`8`

每项模板：

```text
横排
├─ 文字：${item.time}
└─ 文字：${item.title}
```

:::warning 循环最多显示 50 条
接口返回大量数据时，先在 JavaScript 中 `items.slice(0, 50)`。
:::

列表目前不支持分组吸顶、底部吸附和侧滑操作。需要项目点击时，在模板中放按钮或设置了“打开链接”的容器。
