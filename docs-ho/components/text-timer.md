# 计时器

计时器显示正计时或倒计时。组件自己更新，不需要频繁运行 JavaScript。

## 先选择计时方式

| 目标 | 倒计时 | 起点时间戳(ms) | 格式 |
| --- | --- | --- | --- |
| 从现在正计时 | `false` | 留空或 `Date.now()` | `mm:ss` |
| 从指定时刻正计时 | `false` | 起始时间戳 | `HH:mm:ss` |
| 倒计时 | `true` | 结束时间戳 | `mm:ss` 或 `HH:mm:ss` |

“倒计时时长(ms,已弃用)”只为旧卡片保留，新卡片请留空。

## 属性

| 字段 | 常用填写 | 作用 |
| --- | --- | --- |
| 倒计时 | `true` / `false` | 决定时间戳表示起点还是终点 |
| 起点时间戳(ms) | `Date.now()` / `${startTime}` | 正计时的起点或倒计时的终点 |
| 格式 | `mm:ss` / `HH:mm:ss` / `ss` | 显示格式 |
| 字号、行高、字重、字体、文字色 | 固定值或变量 | 文字样式 |
| 宽 / 高、偏移、内外边距 | 数字、百分比或变量 | 通用布局字段 |
| 显示、背景色、圆角、旋转、不透明度 | 固定值或变量 | 通用视觉字段 |

## 示例：5 分钟倒计时

```js
let endTime = Date.now() + 5 * 60 * 1000
```

| 字段 | 填写 |
| --- | --- |
| 倒计时 | `true` |
| 起点时间戳(ms) | `${endTime}` |
| 格式 | `mm:ss` |

## 示例：当天已过时间

```js
const now = new Date()
let startTime = new Date(now.getFullYear(), now.getMonth(), now.getDate()).getTime()
```

“倒计时”设为 `false`，“起点时间戳(ms)”设为 `${startTime}`，“格式”设为 `HH:mm:ss`。

:::warning 倒计时最多显示 24 小时
结束时间超过当前时间 24 小时时，显示会截断到 24 小时；结束时间已经过去时显示 `00:00:00`。
:::
