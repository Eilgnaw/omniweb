# 文字

用文字显示标题、数字、说明，或 JavaScript 返回的数据。

## 最快用法

1. 点编辑器底部 `+`，添加**文字**。
2. 在“内容”中输入固定文字或占位符。

| 内容 | 显示结果 |
| --- | --- |
| `Hello` | Hello |
| `${name}` | 顶层变量 `name` 的值 |
| `你好，${name}。今天 ${temp}°` | 固定文字与变量混排 |

## 属性

| 字段 | 常用填写 | 作用 |
| --- | --- | --- |
| 内容 | `你好` / `${title}` | 显示文字，支持占位符 |
| 字号 | `14` / `14vp` / `${size}` | 文字大小 |
| 行高 | `16` / `20` / `${lineHeight}` | 控制上下占用；留空使用系统默认 |
| 字重 | `normal` / `bold` / `medium` | 文字粗细 |
| 字体 | 编辑器下拉选项 | 指定字体 |
| 文字色 | `#000000` / `${color}` | 纯色或颜色变量 |
| 文字描边 | 编辑器内设置 | 设置启用、宽度和颜色 |
| 宽 / 高、偏移、内外边距 | 数字、百分比或变量 | 通用布局字段 |
| 显示、背景色、圆角、旋转、不透明度 | 固定值或变量 | 通用视觉字段 |

## 示例：显示两项数据

```js
let title = "未读消息"
let count = 12
```

```text
${title}
${count}
${title}：${count} 条
```

## 动态字号

“字号”填写 `${size}`：

```js
let size = 24
```

整段占位符会保留数字类型。需要固定单位时，直接填写 `24vp`、`24fp` 或 `24px`。

## 文字描边

描边标题可以这样设置：

| 字段 | 填写 |
| --- | --- |
| 内容 | `Omni Widgets` |
| 字号 | `48` |
| 字重 | `bold` |
| 文字色 | `#FFFFFF` |
| 文字描边 | 开启；宽度 `2`；颜色 `#000000` |

:::warning 描边限制
描边文字按单行显示；换行会变成空格。前景使用渐变时不显示描边。宽度不足时会横向缩放，不会自动换行。
:::
