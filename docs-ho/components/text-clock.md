# 时钟

时钟显示当前系统时间，不需要 JavaScript，也不需要设置卡片刷新频率。

## 最快用法

添加**时钟**，在“格式”中填写：

| 格式 | 示例 |
| --- | --- |
| `HH:mm` | `17:00` |
| `aa hh:mm` | `下午 05:00` |
| `yyyy年M月d日` | `2026年6月5日` |
| `M月d日 EEEE` | `6月5日 星期五` |

## 属性

| 字段 | 常用填写 | 作用 |
| --- | --- | --- |
| 格式 | `HH:mm` / `yyyy/M/d` / `M月d日 EEEE` | 决定显示内容 |
| 时区偏移 | `-8` / `5` | 留空跟随系统；东八区填写 `-8` |
| 字号、字重、字体、文字色 | 固定值或变量 | 文字样式 |
| 宽 / 高、偏移、内外边距 | 数字、百分比或变量 | 通用布局字段 |
| 显示、背景色、圆角、旋转、不透明度 | 固定值或变量 | 通用视觉字段 |

## 常用格式字符

| 写法 | 含义 |
| --- | --- |
| `yyyy` / `yy` | 年 |
| `M` / `MM` | 月 |
| `d` / `dd` | 日 |
| `E` / `EEEE` | 星期 |
| `H` / `HH` | 24 小时制 |
| `h` / `hh` | 12 小时制 |
| `m` / `mm` | 分钟 |
| `a` | 上午 / 下午 |

:::warning 卡片最小时间单位是分钟
不要依赖 `ss`、`SS` 或 `SSS` 在卡片上显示秒和毫秒。需要秒级计时请使用[计时器](./text-timer.md)。
:::
