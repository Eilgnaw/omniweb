# 网格

网格按固定行列展示内容，适合图标入口、指标面板和小型宫格。

## 最快用法

1. 添加**网格**。
2. 设置方向、列数和间距。
3. 放入一个根子组件作为格子模板。
4. 需要动态数量时，设置“数据源（循环）”。

## 属性

| 字段 | 常用填写 | 作用 |
| --- | --- | --- |
| 方向 | `horizontal` / `vertical` | 横向先从左到右；纵向先从上到下 |
| 列数 / 行数 | `3` / `${count}` | 横向表示每行列数；纵向表示每列条数 |
| 间距 | `0` / `8` | 行列之间的距离 |
| 数据源（循环） | `{items[item]}` | 按数组重复格子模板 |
| 宽 / 高、偏移、内外边距 | 数字、百分比或变量 | 通用布局字段 |
| 显示、背景色、圆角、旋转、不透明度 | 固定值或变量 | 通用视觉字段 |

## 示例：三列入口

```js
let items = [
  { name: "音乐", icon: "music" },
  { name: "相机", icon: "camera" },
  { name: "天气", icon: "cloud" },
  { name: "时钟", icon: "clock" }
]
```

网格设置：

- 方向：`horizontal`
- 列数 / 行数：`3`
- 间距：`8`
- 数据源（循环）：`{items[item]}`

格子模板：

```text
纵列
├─ 图标：${item.icon}
└─ 文字：${item.name}
```

:::tip 网格只有一个根模板
需要一个格子里同时出现图标和文字时，先用纵列、横排或层叠包起来，再把这个容器放进网格。
:::

网格不滚动。数据很多或需要上下、左右滚动时，使用[列表](./list.md)。循环同样最多展开 50 条。
