# 占位

占位会撑开容器中的剩余空间，把前后组件推向两端。

## 最快用法

```text
横排
├─ 文字（标题）
├─ 占位
└─ 文字（26°）
```

标题靠左，温度靠右。

## 属性

| 字段 | 常用填写 | 作用 |
| --- | --- | --- |
| 最小占位 | `10` / `10px` / `10vp` | 占位至少多大；留空时自动撑开 |
| 显示 | `true` / `false` / `${show}` | 控制是否参与布局 |

:::warning 不支持百分比和负值
`50%`、负数或无效值会被忽略。需要固定比例时，请设置容器或相邻组件宽度。
:::

多个占位会平分剩余空间。需要固定间距时，使用容器的“内间距”，不要添加多个占位模拟固定距离。
