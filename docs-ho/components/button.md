# 按钮

按钮是可点击容器。子组件决定外观，“点击”字段决定执行什么代码。

## 最快用法

1. 添加**按钮**。
2. 在按钮中放入文字、图标或图片。
3. 在“点击”中填写简短的 JavaScript 调用。

```text
按钮
├─ 图标（plus）
└─ 文字（添加）
```

## 推荐写法

把完整逻辑放在主脚本函数中，按钮只负责调用：

```js
let count = Config.get("count", 0)

function increment() {
  count += 1
  Config.set("count", count)
}
```

“点击”填写：

```text
increment()
```

异步函数可以写 `await refreshData()`。特殊值 `refresh` 表示重新运行并刷新。

## 属性

| 字段 | 常用填写 | 作用 |
| --- | --- | --- |
| 点击 | `increment()` / `await refreshData()` / `refresh` | 点击后运行的脚本片段 |
| 宽 / 高、偏移、内外边距 | 数字、百分比或变量 | 通用布局字段 |
| 显示、背景色、圆角、旋转、不透明度 | 固定值或变量 | 通用视觉字段 |

按钮中的文字、字号和颜色由内部子组件设置。

:::warning 点击代码也有时间上限
不要在“点击”中粘贴大段逻辑或顶层 `return`。耗时操作写成主脚本函数，并提供失败回退。
:::

要直接打开网页或应用，请使用容器的“打开链接”，不要用按钮绕一层脚本。
