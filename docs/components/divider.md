# 分割线 Divider

Divider 用系统分割线隔开相邻内容，会根据所在容器自动选择方向。

## 方向

| 所在位置 | 显示方向 |
| --- | --- |
| `vstack` | 横向，填满容器宽度 |
| `hstack` | 纵向，填满容器高度 |
| 其他位置 | 横向 |

## 常用属性

| 属性 | 作用 |
| --- | --- |
| 内边距 | 控制分割线两端或上下留白 |
| 不透明度 | 调整分割线的明暗程度 |
| 运行时隐藏 | 用固定值或占位符控制是否显示 |

## 示例：列表分隔线

```text
vstack
├─ hstack（第一行内容）
├─ divider（左右内边距：10）
└─ hstack（第二行内容）
```

如果最后一行不需要分割线，可以把“运行时隐藏”设为 `${item.hideDivider}`，并让最后一项的 `hideDivider` 为 `1`。
