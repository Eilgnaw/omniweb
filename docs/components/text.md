# 文本 Text

用 Text 显示标题、数字、说明文字，或 JavaScript 返回的数据。

## 最快用法

1. 在编辑器右上角点 `+`，添加 **text**。
2. 在“内容”里输入固定文字或占位符。

| 内容 | 显示结果 |
| --- | --- |
| `Hello` | Hello |
| `${name}` | `this.name` 的值 |
| `你好，${name}。今天 ${temp}°` | 固定文字与变量混排 |

占位符的完整规则见[占位符语法](../getting-started/placeholder.md)。

## 常用属性

| 属性 | 作用 |
| --- | --- |
| 内容 | 要显示的文字或占位符 |
| 字号 | 固定数字或占位符，例如 `${size}` |
| 字体 | 系统字体或自定义字体 |
| 颜色 | 单色或渐变前景色 |
| 行数 | `0` 表示不限制；`1` 表示单行 |
| 字号缩放 | 文字过长时允许缩小到的比例 |
| 截断模式 | 空间仍不足时，从头部、中间或尾部截断 |
| 对齐 | 居左、居中或居右 |
| 背景与圆角 | 给文字区域添加底色和圆角 |
| 旋转与偏移 | 调整文字的位置和角度 |

## 示例：显示两项 JS 数据

```js
this.title = "未读消息"
this.count = 12
```

| 用途 | 内容 |
| --- | --- |
| 标题 | `${title}` |
| 数字 | `${count}` |
| 合并显示 | `${title}：${count} 条` |

:::tip 文字放不下时
先限制行数，再调整字号缩放和截断模式。不要一开始就把字号写得很小，否则短内容也会失去层级。
:::
