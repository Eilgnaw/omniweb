# 形状 Shape

用 Shape 做背景、分隔线、圆点、胶囊或简单进度条。

## 最快用法

1. 添加 **shape**。
2. 在“内容”里选择形状。
3. 设置宽高和颜色。

| 内容 | 形状 |
| --- | --- |
| `circle` | 圆形 |
| `rectangle` | 矩形 |
| `roundedrectangle` | 圆角矩形 |
| `ellipse` | 椭圆 |
| `capsule` | 胶囊 |

## 常用属性

| 属性 | 作用 |
| --- | --- |
| 宽 / 高 | 形状尺寸 |
| 颜色 | 单色或渐变填充 |
| 圆角 | 仅用于圆角矩形 |
| 不透明度 | `0` 到 `1` |
| 旋转 / 偏移 | 调整角度和位置 |

## 示例：简单进度条

在 `zstack` 中叠放两个矩形：

| 层级 | 内容 | 宽度 | 颜色 |
| --- | --- | --- | --- |
| 底层 | `rectangle` | `100` | 灰色 |
| 上层 | `rectangle` | `${percent}` | 主题色 |

```js
this.percent = 60
```

上层宽度变为 60，形成 60% 的进度条。

:::tip 需要系统样式的进度？
使用 [Gauge](./gauge.md)。需要折线、圆弧或多段图形时，使用 [Canvas](./canvas.md)。
:::
